# PR: feature/gameplay-updates -> main

Ветка feature/gameplay-updates содержит рефакторинг для локальной разработки и модульный перенос игровой логики:

Что включено:
- index.html: безопасная загрузка оригинальной страницы (body) и последовательная вставка/выполнение внутренних скриптов; подключение game.js и styles.css.
- game.js: модульный bootstrap с управлением настройками (localStorage), SVG hex grid генератором, UI-контролами для разработки (Настройки, Конец хода, Купить топливо), API для отладки (GAME.*).
- Удалён/пропущен внешний подозрительный скрипт (внешние origin) для локальной разработки.

Задачи/ограничения:
- Ветка ещё в процессе: оставшиеся inline‑скрипты оригинала будут перенесены в модули при следующем шаге.
- Пока что логика игры сохраняется, но интеграция со старым кодом выполняется поэтапно.

Просьба к ревьюерам:
- Проверить подход к безопасной загрузке скриптов и отсутствие внешних зависимостей.
- Замечания по API GAME.* и структуре генерируемого SVG приветствуются.

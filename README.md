# Maze Tile Generator v2.1

## Быстрый старт

Откройте `index.html` в современном браузере. Приложение работает полностью локально без зависимостей.

## Новое в v2.1 — Tile Editor 🎨

### Два режима работы

#### 1. **Генератор** (Generator Mode)
- Стандартная процедурная генерация лабиринтов
- Контроль сложности, плотности декора, случайного семени
- Экспорт полного поля и sprite sheet
- **Точно как в v2** — полная совместимость

#### 2. **Редактор** (Editor Mode)
- Кликните на любой тайл на поле для редактирования
- **Сокеты N/E/S/W**: Открывайте/закрывайте коридоры в любую сторону
- **Цвета**: Настраивайте цвет пола и стен отдельно для каждого тайла
- **Фиксация тайлов**: Заблокируйте тайл, чтобы он не менялся при регенерации
- **История**: Undo/Redo для всех изменений
- **Экспорт**: Сохраняйте отдельные тайлы в **PNG или SVG**

### Workflow редактора

```
1. Переключитесь в режим "Редактор"
2. Кликните на тайл → откроется панель редактирования
3. Используйте кнопки N/E/S/W для открытия проходов
4. Выберите цвета в color pickers
5. Чекбокс "Зафиксировать" для сохранения при регенерации
6. "Применить" → изменения применяются
7. "Экспорт PNG/SVG" → скачайте отдельный тайл

История сохраняется автоматически. Используйте Undo/Redo для отката.
```

## Архитектура

### Генератор
1. `graph()` создаёт связный граф поля (Kruskal)
2. Граф переводится в 4-битные маски N/E/S/W
3. `tile()` строит визуальный слой на основе маски и theme profile
4. `decorObj()` размещает декоративные элементы только за пределами прохода
5. `validate()` проверяет стыки и достижимость всех клеток
6. Экспорт сохраняет результат и данные, необходимые для повторной сборки

### Редактор
- **Tile Selection**: Клик на canvas выбирает тайл по координатам
- **Socket Editing**: Toggle-кнопки модифицируют 4-битную маску
- **State Management**: Каждое изменение сохраняется в history stack
- **Pinned Tiles**: Set<number> сохраняет индексы зафиксированных тайлов
- **Color Overrides**: Map<number, {floor, wall}> хранит кастомные цвета
- **Undo/Redo**: Полные снимки состояния в истории

## Экспорт

### Все форматы
- **PNG поля** — весь лабиринт в одном файле (tileSize × gridSize)
- **PNG тайла** — отдельный тайл высокого качества (для редактора)
- **SVG тайла** — вектор отдельного тайла (масштабируемый, редактируемый)
- **Sprite Sheet** — все 60 комбинаций (15 форм × 4 варианта) в одном файле
- **JSON топологии** — маски тайлов, зафиксированные, переопределения цветов
- **JSON темы** — палитра и правила декора
- **Project** — полное состояние для восстановления сессии

### Примеры файлов

```
maze_temple_481729.png          ← весь лабиринт
tile_42_temple.png              ← отдельный тайл (PNG)
tile_42_temple.svg              ← отдельный тайл (SVG, вектор)
spritesheet_temple.png          ← все варианты (5×6 сетка)
maze_temple_481729.json         ← топология + история редактирования
theme_temple.json               ← палитра и правила
project_1234567890.json         ← вся сессия с undo/redo
```

## Важное замечание

Это художественный procedural prototype, а не финальный набор коммерческих игровых ассетов. Для production-качества следует заменить `decorObj()` на импорт настоящих спрайтов и добавить профессиональное микширование текстур.

## Требования

- Современный браузер с поддержкой:
  - Canvas 2D Context
  - `roundRect()` метода
  - `toBlob()` для экспорта
  - ES6+ JavaScript

## Примеры использования

### Использование в игре
```javascript
// Загрузить JSON топологии
const maze = await fetch('maze_temple_481729.json').then(r => r.json());

// maze.gridSize × maze.gridSize сетка
// maze.masks — массив 4-битных масок
// maze.pinned — заблокированные тайлы
// maze.overrides — кастомные цвета

for (let y = 0; y < maze.gridSize; y++) {
  for (let x = 0; x < maze.gridSize; x++) {
    const mask = maze.masks[y * maze.gridSize + x];
    const hasNorth = mask & 1;
    const hasEast = mask & 2;
    const hasSouth = mask & 4;
    const hasWest = mask & 8;
    // Используйте для логики игры
  }
}
```

### Экспорт отдельных тайлов
1. Переключитесь в режим "Редактор"
2. Выделите нужный тайл
3. Настройте сокеты и цвета
4. Нажмите "📥 PNG" или "📥 SVG"
5. Тайл скачается в формате `tile_<index>_<theme>.<ext>`

### Коллаборация с другими инструментами
- **Sprite Sheet** для tile-based редакторов (Tiled, Aseprite)
- **SVG тайлы** для Inkscape, Illustrator (редактирование геометрии)
- **JSON** для собственных инструментов обработки

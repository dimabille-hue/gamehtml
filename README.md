# Maze Tile Generator v2

## Запуск
Откройте `index.html` в современном браузере.

## Что добавлено по сравнению с v1
- 4 полноценных theme profiles.
- Разделение Topology / Theme / Decoration.
- 15 форм тайлов × 4 варианта.
- Контролируемая плотность декора.
- Безопасная зона вокруг прохода.
- Проверка полной связности и N/E/S/W стыков.
- JSON темы отдельно от JSON поля.
- Экспорт PNG поля + Sprite Sheet + JSON.
- Сетка, zoom, seed, новый seed.
- Сохранение проекта.
- Локальная генерация без зависимостей.

## Архитектура
1. `graph()` создаёт связный граф поля.
2. Граф переводится в 4-битные маски N/E/S/W.
3. `tile()` строит визуальный слой на основе маски и theme profile.
4. `decorObj()` размещает декоративные элементы только за пределами прохода.
5. `validate()` проверяет стыки и достижимость всех клеток.
6. Экспорт сохраняет результат и данные, необходимые для повторной сборки.

## Важное замечание
Это художественный procedural prototype, а не финальный набор коммерческих игровых ассетов. Для production-качества следующий этап — заменить простые Canvas-фигуры на авторские текстуры/спрайты/PBR-материалы и добавить редактор Theme/Tile Rules.
